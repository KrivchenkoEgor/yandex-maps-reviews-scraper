## 🎯 Проект: Yandex Reviews Scraper

### Суть
Веб-сервис, который принимает **ссылку на магазин** на Яндекс.Картах и скачивает **все отзывы** этого магазина с полной метаданной:

```json
{
  "shop": {
    "name": "Магнит",
    "address": "Красный проспект, 50",
    "rating": 4.3,
    "total_reviews": 247
  },
  "reviews": [
    {
      "review_id": "abc123",
      "author": "Иван П.",
      "rating": 5,
      "date": "2024-03-15",
      "text": "Отличный магазин, всегда свежие продукты...",
      "photos": ["https://..."],
      "owner_response": {
        "text": "Спасибо за отзыв!",
        "date": "2024-03-16"
      },
      "likes": 12,
      "is_verified": true
    }
  ]
}
```

### Входные данные
- **Короткая ссылка**: `https://yandex.ru/maps/-/CTwsUYyk`
- **Полная ссылка**: `https://yandex.ru/maps/65/novosibirsk/?ll=...&poi[uri]=ymapsbm1://org?oid=1659941740&tab=reviews`

### Три режима работы
| Режим | Описание |
|-------|----------|
| **Одиночный** | Одна ссылка → скачать все отзывы → показать статистику → экспорт |
| **Пакетный** | Excel со списком ссылок → обработка по очереди → единый отчёт |
| **Мониторинг** | Подписка на магазин + интервал (день/неделя) → уведомление о новых отзывах |

## 🔍 Стратегия парсинга Яндекс.Карт

### Шаг 1: Разрешение короткой ссылки
Если дана короткая ссылка `yandex.ru/maps/-/XXX`:
1. HTTP HEAD запрос с `allow_redirects=True`
2. Получение финального URL после всех редиректов
3. Извлечение параметров: `poi[uri]`, `poi[point]`, `ll`, `z`

### Шаг 2: Извлечение oid организации
Из `poi[uri]` вида `ymapsbm1://org?oid=1659941740` извлекаем `oid=1659941740` — это уникальный ID магазина.

### Шаг 3: Открытие страницы в Playwright
- Запуск Chromium с User-Agent ротацией
- Переход на страницу с `tab=reviews`
- Ожидание загрузки блока отзывов

### Шаг 4: Бесконечный скролл
Цикл:
1. Скролл до конца списка отзывов
2. Пауза 2–5 сек (ожидание подгрузки новых)
3. Проверка: появились ли новые отзывы
4. Если нет новых за 3 итерации — стоп
5. Если появились — продолжаем

### Шаг 5: Извлечение метаданных отзыва
Для каждого отзыва:
- Автор (имя/ник)
- Рейтинг (1–5 звёзд)
- Дата (с преобразованием «3 дня назад» → дату)
- Полный текст
- Ссылки на фото (если есть)
- Ответ владельца (если есть)
- Количество лайков
- Признак «Проверенный отзыв»

### Шаг 6: Сохранение
- В SQLite (для кэша и мониторинга)
- В Excel/CSV/JSON (для экспорта пользователю)

## 🛡 Антибот-защита

| Защита | Реализация |
|--------|------------|
| **Rate limiting** | Пауза 2–5 сек между действиями (рандом) |
| **User-Agent ротация** | Список из 10 реальных UA (Chrome, Firefox, Safari на Win/Mac/Linux) |
| **Viewport рандом** | Разные размеры окна браузера |
| **Задержки мыши** | Имитация человеческих движений между кликами |
| **Retry** | Exponential backoff при ошибках (3 попытки) |
| **Капча** | Детекция → пауза 30 сек → повтор; если не помогло → запрос пользователю |

## 💾 Кэширование в SQLite

### Таблица `shops`
| Поле | Тип | Описание |
|------|-----|----------|
| `oid` | TEXT PK | ID организации |
| `name` | TEXT | Название магазина |
| `address` | TEXT | Адрес |
| `rating` | REAL | Средний рейтинг |
| `total_reviews` | INTEGER | Всего отзывов |
| `last_scraped` | DATETIME | Последнее обновление |
| `url` | TEXT | Полная ссылка |

### Таблица `reviews`
| Поле | Тип | Описание |
|------|-----|----------|
| `review_id` | TEXT PK | Уникальный ID отзыва |
| `shop_oid` | TEXT FK | Магазин |
| `author` | TEXT | Автор |
| `rating` | INTEGER | 1-5 |
| `date` | DATE | Дата отзыва |
| `text` | TEXT | Полный текст |
| `photos` | TEXT | JSON-массив URL |
| `owner_response` | TEXT | JSON {text, date} |
| `likes` | INTEGER | Лайки |
| `is_verified` | BOOLEAN | Проверенный |
| `scraped_at` | DATETIME | Когда скачан |

### Таблица `monitoring`
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER PK | Автоинкремент |
| `shop_oid` | TEXT FK | Магазин |
| `interval_hours` | INTEGER | Период проверки |
| `last_check` | DATETIME | Последняя проверка |
| `active` | BOOLEAN | Включено |

### Таблица `scrape_log` (для статистики)
- Время начала/конца, shop_oid, количество отзывов, статус, ошибки

### Логика работы
- Перед скачиванием: проверить, есть ли магазин в кэше
- Если есть и последнее обновление < 24 часов → спросить: «Скачать заново или взять из кэша?»
- Если нет → скачать, сохранить в кэш
- При мониторинге: сравнивать `review_id` с существующими, добавлять только новые
